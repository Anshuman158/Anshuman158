## About Me

I'm a Computer Science undergraduate at **Vellore Institute of Technology, Bhopal**, focused on backend engineering, distributed systems fundamentals, and AI-powered application development. My work centers on building **secure, ACID-compliant systems with proper concurrency control**, and shipping full-stack applications with modern JavaScript tooling.

- 🔧 Comfortable across the stack — from **React/Vite frontends** to **Node.js/Express/PostgreSQL backends**
- 🏦 Interested in **financial systems engineering** — ledgers, transaction integrity, and concurrency-safe design
- 🤖 Exploring **AI/ML fundamentals** (NPTEL Deep Learning) and applying them to product-facing tools
- ☁️ Building working knowledge of **AWS (S3, EC2, VPC)** for deployment and infrastructure

**Open to:** Backend Engineering Internships · Full-Stack Development Roles · Open Source Collaboration

|---|---|
